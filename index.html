Configuration

À faire une seule fois dans l'app Raccourcis de ton iPhone (environ 10 minutes).

1. Raccourci « Focus Demarrer »

Il enregistre l'heure de fin du blocage.

  1. Raccourcis → onglet Raccourcis → +. Nomme-le exactement Focus Demarrer (sans accent).
  2. Ajoute l'action Ajuster la date : Ajouter → valeur : la variable Entrée du raccourci → unité minutes → à Date actuelle.
  3. Ajoute l'action Texte et mets-y la variable Date ajustée.
  4. Ajoute Enregistrer le fichier : enregistre le Texte, désactive Demander où enregistrer, sous-chemin focus-fin.txt, active Remplacer si le fichier existe.

2. Raccourci « Focus Arreter »

  1. Nouveau raccourci nommé Focus Arreter.
  2. Action Texte contenant la variable Date actuelle.
  3. Enregistrer le fichier avec exactement les mêmes réglages qu'à l'étape 1 (focus-fin.txt, remplacer).

3. Raccourci « Focus Verifier »

  1. Nouveau raccourci nommé Focus Verifier.
  2. Obtenir le fichier : sous-chemin focus-fin.txt, désactive Afficher le sélecteur et Erreur si introuvable.
  3. Obtenir les dates de → Fichier.
  4. Si → Date actuelle est avant Dates.
  5. Dans le Si : Ouvrir les URL avec cette adresse :

4. Automatisation des apps

  1. Raccourcis → onglet Automatisation → + → App.
  2. Choisis : . Coche Est ouverte.
  3. Choisis Exécuter immédiatement et désactive Avertir lors de l'exécution.
  4. Action : Exécuter le raccourci → Focus Verifier.

5. Mettre l'app sur ton écran d'accueil

  1. Ouvre cette page dans Safari.
  2. Touche Partager → Sur l'écran d'accueil.

Ouvre toujours l'app avec cette icône : elle garde tes sessions et ton planning.

Tester

Lance un blocage d'1 minute en mode moyen, puis ouvre TikTok : l'écran de blocage doit apparaître.
